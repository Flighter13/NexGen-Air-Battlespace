## Project status

The GitHub Pages root at `https://flighter13.github.io/NexGen-Air-Battlespace/` is a legacy entry point and now redirects to the current `/research/` application. Please use the research link above in publications, portfolios, and other websites.

The earlier mission-selector prototype is preserved in this repository's Git history; its former root-page implementation should not be treated as the current research interface. This change does not delete the project's historical source files or change the `/research/` application.

## Research focus

NexGen Air Battlespace explores modern air-combat systems and the relationships among aircraft, unmanned platforms, sensing, communications, command-and-control, and mission phases. Its research visualization is intended to explain connected operations rather than serve as an operational planning tool.

## Development and deployment

The current Research Atlas is published under the `/research/` path. The repository root `index.html` is intentionally a lightweight redirect and should not be replaced with the historical homepage during subsequent updates.

To work on the current application, first identify the source and deployment workflow for the `/research/` bundle; the historical HTML, CSS, and JavaScript files in the repository are not automatically the authoritative source for the research application.
