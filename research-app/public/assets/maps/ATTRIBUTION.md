# Basemap

Made with Natural Earth. `land.geojson` is Natural Earth's 1:110m land dataset, downloaded from https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson on 2026-09-17.

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

This low-resolution reference map is for visual context, not navigation or operational accuracy. It is bundled locally so the starter does not require a map API key.
